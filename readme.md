# 🏆 League of LLMs
---

**Same Prompt. Multiple AIs. One Winner.**

League of LLMs is a platform where multiple AI models compete head-to-head on the same prompt. Users compare responses blindly, vote for the best answer, and discover which model performs best across different categories.

## ✨ Features

* 🤖 Multi-model AI battles
* 🕵️ Blind response comparison
* 🗳️ Community voting system
* 📊 Global leaderboards
* 🏷️ Category-based rankings
* 📜 Battle history and analytics
* 👤 User profiles and saved battles
* 🌙 Modern dark-mode interface

## 🎯 Problem

With so many AI models available today, it is difficult to know which one performs best for specific tasks such as coding, writing, research, or creativity.

League of LLMs provides an unbiased comparison environment where users evaluate responses before knowing which model generated them.

## 🚀 How It Works

1. Enter a prompt.
2. Select AI models to compete.
3. Generate responses from each model.
4. Compare answers anonymously.
5. Vote for the best response.
6. Reveal the models behind each answer.
7. Update rankings and leaderboards.
